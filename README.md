# Handwritten Digit Recognition using CNN

## About the Project

This project uses a Convolutional Neural Network (CNN) to recognize handwritten digits (0–9) from images.

## Technologies Used

* Python
* TensorFlow / Keras
* NumPy
* Matplotlib
* Google Colab

## Dataset

The project uses the MNIST dataset, which contains handwritten digit images from 0 to 9.

## Objective

To build and train a CNN model that can accurately classify handwritten digits.
